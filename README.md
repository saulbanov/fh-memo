# fh-memo

Web copy of Future Heist's post-election funder memo (November 2026), served by GitHub Pages at
https://saulbanov.github.io/fh-memo/. The page is `noindex`; it is shared only by link.

`index.html` is generated from `future-heist/fhwr-runway/working/memo-send/Future_Heist_memo.html`
(itself built from `Future_Heist_memo_formatted.docx`). Edit the memo there and regenerate; don't hand-edit here.

Each funder gets a link with an `?r=<code>` tag. The code-to-recipient key is kept privately in
`memo-send/memo-links.csv`, never in this repo. Visits are counted by GoatCounter once `GC` in `index.html` is set.
